Privacy Policy

Last updated: November 10, 2026

Alden Health Data is a personal tool used only by its owner.

What data is accessed

With the owner's consent, the app reads activity and fitness data (such as exercise sessions and steps) from the owner's own Google Health account, using read-only access.

How it is used

The data is copied into the owner's private data storage and used only for the owner's personal reports.

Sharing

The data is not sold, shared with, or transferred to any third party, and is not used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions. Stored data can be deleted on request.
